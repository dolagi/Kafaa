# Platform User Settings

Standalone Odoo 18 addon depending only on `base`.

Shows only Internal User in the user type selector and hides the Multi Companies
permission on user forms. Existing memberships and company access are preserved.

Copy `platform_user_settings` into your server addons directory, or add this
repository's `addons` directory to `addons_path`. Restart Odoo, update the Apps
list, and install **Platform User Settings** (or upgrade it if already installed).
